# きょうりゅう音読ミッション リニューアル版

小学高学年向けに刷新したPWA版です。

## 主な変更

- 物語本文を、小学6年生くらいでも幼く感じにくい文体へ全面改稿
- リアル寄りの白亜紀・恐竜ビジュアルに変更
- 音読画面を、左にイラスト・右に本文の分割レイアウトへ変更
- テキストとイラストの重なりを解消
- デフォルト文字サイズを小さめにし、文章量を増加
- `localStorage` に進捗・スタンプ・文字サイズを保存
- PWAキャッシュ名を `spino-ondoku-redesign-v1` に更新

## GitHub Pagesへの反映

このフォルダの中身をリポジトリに上書きアップロードしてください。PWAのため、表示が古い場合はブラウザ再読み込み、またはホーム画面アイコンの再追加を行ってください。


## redesign-v3 更新内容
- 音読ページのレスポンシブ構成を全端末で「左：画像 / 右：文章」に統一。
- 音読ページ・ミッション一覧の画像をSVGベースの高解像度クリア版に差し替え。
- PWAキャッシュ名を spino-ondoku-redesign-v3 に更新。

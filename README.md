# きょうりゅう音読ミッション - 自分専用PWA版

## 使い方

1. ZIPを解凍します。
2. 解凍したフォルダの中身を Netlify Drop / GitHub Pages / Vercel などの静的ホスティングにアップロードします。
3. 発行されたURLをタブレットで開きます。
4. ホーム画面に追加します。

### iPad
Safariで開く → 共有ボタン → ホーム画面に追加

### Android
Chromeで開く → メニュー → ホーム画面に追加 / アプリをインストール

## データについて

進捗とスタンプはタブレットのブラウザ内に保存されます。サーバーには送信されません。

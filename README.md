# きょうりゅう音読ミッション SVG版

公開版でも絵文字ではなくSVG描画のイラストが出るように修正した版です。

## GitHub Pagesでの更新

このZIPを解凍し、中身を既存リポジトリへ上書きアップロードして Commit changes してください。

古い絵文字版が残る場合は、ブラウザまたはPWAのキャッシュが残っています。iPadではホーム画面のアイコンを一度削除し、Safariで開き直してから再度「ホーム画面に追加」してください。

- デスクトップ、タブレット、スマートフォンでイオリくんや恐竜が見切れにくくなります。

古い表示が残る場合は、ページを数回再読み込みするか、ホーム画面に追加済みのアイコンを一度削除して再追加してください。
